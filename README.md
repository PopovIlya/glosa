# Glosa: словарь по выделению

macOS-приложение в строке меню. Выдели слово или фразу на испанском или английском в любом приложении и нажми **⌃⌥T**: Claude вернёт словарную статью, а слова попадут в колоду для повторения.

- **Фраза:** перевод целиком, затем каждое слово отдельно: начальная форма (`levantamos ← levantarse`, «1 л. мн. ч., presente»), значение в этом контексте и другие значения.
- **Слово:** главное значение, до пяти других, два примера.
- **Произношение:** фонетическая транскрипция (МФА: `/le.βanˈta.mos/`, испанский в кастильском варианте, английский британский), слоги с выделенным ударным (`le·van·**ta**·mos`), чтение русскими буквами с ударением (`левантáмос`), 🔊 читает голосом macOS.
- **Спряжение:** у глаголов кнопка «Спряжение». Испанский: 8 времён/наклонений, английский: основные времена и формы (past, participle, -ing). Загружается отдельным запросом, только когда нажмёшь.
- **Словарь:** знаменательные слова (без артиклей, предлогов, союзов и безударных местоимений) сразу добавляются в колоду своего языка в начальной форме:
  - испанские в `~/Claude/spanish/vocab.json`, ту же Leitner-колоду, что у уроков и ежедневного повторения (`source: "glosa"`, box 1, due завтра);
  - английские в `~/Claude/english/vocab.json` (создаётся с первым словом, тот же формат, ключ `en`).

  Дубли пропускаются (`gracioso` уже покрыт картой `divertido/a, gracioso/a`). ✓ у слова: добавлено, клик убирает; 🔖: уже было; ⊕: добавить вручную (например, предлог). Остальной файл не переписывается: форматирование совпадает с Python `json.dumps(indent=2, ensure_ascii=False)`.

## Запуск

```bash
cd ~/Claude/glosa
cp .env.example .env   # ANTHROPIC_API_KEY, если есть
./scripts/bundle.sh
open build/Glosa.app
```

**Доступ к Claude:**
1. `ANTHROPIC_API_KEY` в `.env`: прямой запрос к Messages API, самый быстрый.
2. Без ключа Glosa вызывает CLI `claude` (`claude -p`) с твоим аккаунтом. CLI должен быть залогинен: запусти `claude` в терминале и выполни `/login`.

Модель: через API `claude-opus-5-5` (effort low, сменить: `CLAUDE_MODEL`); через CLI алиас `opus`: каждая версия CLI сама выбирает самую новую модель, которую поддерживает (сменить: `CLAUDE_CLI_MODEL`). Через CLI 2.1.108 (opus 4.6) слово переводится за ~9 с, фраза за ~17 с, спряжение за ~25 с; у одиночного глагола спряжение грузится заранее, в фоне.

macOS попросит доступ в **Универсальный доступ**: Glosa копирует выделение через ⌘C и возвращает буфер обмена как был. Без разрешения: меню 📖 → «Перевести буфер обмена», или впиши слово в поле наверху панели.

Демо без сети и ключа (словарь пишется во временную папку): `open build/Glosa.app --args --demo --ask "Nos levantamos muy temprano"`.

## Устройство

| Файл | Что делает |
|---|---|
| [Prompt.swift](Sources/GlosaCore/Prompt.swift) | промпты и JSON-схемы (structured outputs) |
| [Claude.swift](Sources/GlosaCore/Claude.swift) | Messages API или `claude` CLI, `Lexicon.translate / conjugate` |
| [Vocab.swift](Sources/GlosaCore/Vocab.swift) | запись в Leitner-колоду, дедупликация |
| [OrderedJSON.swift](Sources/GlosaCore/OrderedJSON.swift) | JSON с сохранением порядка ключей |
| [TranslatorView.swift](Sources/Glosa/TranslatorView.swift) | панель |

Выделенный текст передаётся модели внутри `<text>` как данные; инструкции из него не выполняются.

Тесты: `swift test`. С настоящими запросами: `GLOSA_LIVE=1 swift test --filter LiveTests`.
