# Glosa: словарь по выделению

macOS-приложение в строке меню. Выдели слово или фразу на испанском или английском в любом приложении и нажми **⌃⌥T**: появится словарная статья, а слова попадут в колоду для повторения.

Слова ищутся во **встроенном словаре** (Викисловарь), поэтому отдельное слово переводится мгновенно и без сети. **Claude** нужен только для перевода фразы целиком и для слов, которых в словаре нет.

- **Слово:** значения из Викисловаря, примеры, начальная форма для любой формы слова (`tuvimos ← tener`, «1 л. мн. ч., indefinido»; `went ← go`, past simple). Если вариантов несколько, показываются все: `como` и как «как», и как форма `comer`.
- **Фраза:** карточки известных слов сразу; перевод фразы, примечание об идиоме и карточки незнакомых слов от Claude через пару секунд. После `nos`, `me`, `se` глагол понимается как возвратный (`nos levantamos ← levantarse`).
- **Произношение:**
  - испанское считается по правилам чтения: слоги с выделенным ударным (`le·van·**ta**·mos`), фонетическая транскрипция МФА в кастильском варианте (`/le.βanˈta.mos/`), чтение русскими буквами с ударением (`лебанта́мос`: испанское v звучит как b);
  - английское берётся из CMUdict, американский вариант (`/ˈwɔtɚ/`, `уо́тэр`);
  - 🔊 читает голосом macOS.
- **Спряжение:** у глаголов кнопка «Спряжение», таблицы встроены. Испанский: 8 времён и наклонений, возвратные с местоимениями (`me levanto`, `levántate`). Английский: основные времена и формы, неправильные глаголы отдельным списком. Только если глагола нет в словаре, таблицу составляет Claude.
- **Колода:** знаменательные слова (без артиклей, предлогов, союзов и безударных местоимений) сразу добавляются в колоду своего языка в начальной форме:
  - испанские в `~/Claude/spanish/vocab.json`, ту же Leitner-колоду, что у уроков и ежедневного повторения (`source: "glosa"`, box 1, due завтра);
  - английские в `~/Claude/english/vocab.json` (создаётся с первым словом, тот же формат, ключ `en`).

  Дубли пропускаются (`gracioso` уже покрыт картой `divertido/a, gracioso/a`). ✓ у слова: добавлено, клик убирает; 🔖: уже было; ⊕: добавить вручную. Остальной файл не переписывается: отступы и перевод строки в конце остаются такими, какие были.
- **Колода и карточки** (кнопка ▤ в панели или 📖 → «Колода и карточки…», ⌘K): окно с двумя вкладками.
  - «Колода»: обе колоды с поиском, коробкой (●●○○○) и датой повторения; слова из Glosa можно удалить (правый клик).
  - «Карточки»: ползунок от 5 до 50 карточек, язык (испанский, английский, смешанно), направление (слово → перевод или наоборот). Сначала идут слова, которые пора повторить, потом из младших коробок. Пробел показывает ответ, ← «не помню», → «помню». Ответ сразу записывается в колоду по правилам Leitner (верно: следующая коробка, повтор через 2/4/8/16 дней; ошибка: коробка 1, завтра), так что ежедневное повторение видит тот же прогресс. В конце можно повторить ошибки.
- **Кэш:** ответы Claude сохраняются в `~/Library/Application Support/Glosa/cache.json`, повторное выделение того же текста мгновенно.
- **Окно:** тянется за край; кнопка ⤢ в заголовке переключает маленький, средний и большой размер.

## Скорость

Через `claude` CLI 2.1.108 (opus):

| Что | Было (всё через Claude) | Сейчас |
|---|---|---|
| слово из словаря | 9–12 с | ~3 мс |
| спряжение | ~25 с | мгновенно |
| фраза, все слова известны | 17–25 с | карточки сразу, перевод ~2,6 с |
| фраза с 3 незнакомыми словами | 25+ с | карточки сразу, остальное ~8 с |
| слово, которого нет в словаре | 9–12 с | ~4 с |

Большую часть ускорения на фразах дал отказ от JSON-схемы: Claude отвечает простым текстом (перевод, примечание и по строке на незнакомое слово), а произношение для этих слов считается в приложении.

## Запуск

```bash
cd ~/Claude/glosa
cp .env.example .env   # ANTHROPIC_API_KEY, если есть
./scripts/bundle.sh
open build/Glosa.app
```

**Доступ к Claude:**
1. `ANTHROPIC_API_KEY` в `.env`: прямой запрос к Messages API.
2. Без ключа Glosa вызывает CLI `claude` (`claude -p`) с твоим аккаунтом. CLI должен быть залогинен: запусти `claude` в терминале и выполни `/login`.

Модель: через API `claude-opus-5-5` (effort low, сменить: `CLAUDE_MODEL`); через CLI алиас `opus`, каждая версия CLI сама выбирает самую новую модель, которую поддерживает (сменить: `CLAUDE_CLI_MODEL`).

macOS попросит доступ в **Универсальный доступ**: Glosa копирует выделение через ⌘C и возвращает буфер обмена как был. Без разрешения: меню 📖 → «Перевести буфер обмена», или впиши слово в поле наверху панели.

Демо без ключа (колода пишется во временную папку): `open build/Glosa.app --args --demo --ask "Nos levantamos muy temprano"`.

## Словари

Готовые словари лежат в [Sources/GlosaCore/Resources](Sources/GlosaCore/Resources) (~4 МБ, сжатый JSON). Пересобрать их из исходных данных: [scripts/build_dictionary.py](scripts/build_dictionary.py); что скачать и куда положить, написано в `--help`. Источники:

| Данные | Откуда | Лицензия |
|---|---|---|
| значения на русском, примеры, слоги (испанский 15,7 тыс. слов, английский 57,9 тыс.) | Русский Викисловарь, выгрузка [kaikki.org](https://kaikki.org/ruwiktionary/) (wiktextract) | CC BY-SA 4.0 |
| формы испанских слов, таблицы спряжения | Английский Викисловарь, выгрузка [kaikki.org](https://kaikki.org/dictionary/Spanish/) | CC BY-SA 4.0 |
| произношение английских слов | [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict) | BSD-подобная |

Файлы словарей распространяются на условиях CC BY-SA 4.0 (Викисловарь, авторы статей Wiktionary); CMUdict © Carnegie Mellon University.
